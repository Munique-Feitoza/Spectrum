# 🧠 Spectrum

> **Aplicativo nativo Android em Java para autorregulação, plano de crise sensorial e suporte diário à neurodivergência (TEA, TDAH e ansiedade).**

O **Spectrum** foi projetado para oferecer acolhimento, previsibilidade e ferramentas práticas para momentos de desregulação, sobrecarga sensorial e comunicação alternativa.

---

## 🚀 Funcionalidades Principais

* **🔋 Medidor de Bateria Social & Cognitiva (`BatteryActivity`)**: Monitoramento contínuo da energia mental e limites diários de interação.
* **⚡ Plano de Sobrecarga e Crise (`OverloadPlanActivity`, `CrisisActivity`)**: Protocolos imediatos de emergência, descompressão sensorial e plano de segurança pessoal (`SafetyPlanActivity`).
* **🗣️ Prancha de Comunicação Alternativa (`AacBoard`)**: Comunicação Aumentativa e Alternativa (CAA) para momentos de fala não-fluente ou bloqueio verbal (shutdowns).
* **🎨 Roda das Emoções Interativa (`EmotionWheelView`)**: Identificação granular de sentimentos e regulação afetiva em camadas (emoções primárias e secundárias).
* **📝 Registro RPD e TCC (`RpdActivity`, `AbcActivity`)**: Registro de Pensamentos Disfuncionais e análise ABC comportamental para reestruturação cognitiva.
* **📌 Widget Nativo de Tela Inicial (`QuickLogWidgetProvider`)**: Registro instantâneo de humor e botão de emergência sensorial via Android RemoteViews nativo em Java puro, garantindo carregamento imediato sem telas pretas ou atrasos.
* **🛡️ Privacidade Local First**: Armazenamento criptografado e offline via **Room Database** (`SpectrumDatabase`), respeitando a sensibilidade e privacidade do usuário.

---

## 🛠️ Stack Tecnológica

* **Linguagem**: Java / Android SDK
* **Framework UI**: Android Jetpack / Material Design 3 / AppWidgetProvider (RemoteViews)
* **Persistência**: Room DB (SQLite local) com DAOs reativos
* **Arquitetura**: MVVM / Local-First / Clean Architecture
* **SDK Mínimo**: Android 8.0 (API 26+) / SDK Target: Android 15 (API 35)
